# TMSF-Net

This is the official repository for the implementation of **TMSF-Net** for multi-step flood extent forecasting.

## Data Availability

The SAR-derived surface-water maps used in this study were obtained from the Lake-Watershed Science Data Center, National Earth System Science Data Center, National Science & Technology Infrastructure of China ([http://lake.geodata.cn](http://lake.geodata.cn)). SWOP was derived from the historical SAR-derived surface-water maps.

The Copernicus GLO-30 digital elevation model (DEM) was obtained from OpenTopography and is available at [https://doi.org/10.5069/G9028PQB](https://doi.org/10.5069/G9028PQB). Slope, TPI, and TRI were derived from the Copernicus GLO-30 DEM using QGIS.

The GLC_FCS30D land-cover dataset is available at [https://doi.org/10.5281/zenodo.8239305](https://doi.org/10.5281/zenodo.8239305).

Daily precipitation data were obtained from the CHM_PRE V2 dataset and are available at [https://doi.org/10.11888/Atmos.tpdc.300523](https://doi.org/10.11888/Atmos.tpdc.300523).

Air-temperature data were obtained from the China Meteorological Forcing Dataset v2.0 and are available at [https://doi.org/10.11888/Atmos.tpdc.302088](https://doi.org/10.11888/Atmos.tpdc.302088).

Daily surface net radiation data were obtained from the Global Land Surface Satellite (GLASS) All-Wave Net Radiation product, available through the GLASS data portal at [https://glass.hku.hk/](https://glass.hku.hk/).

## Code Availability

The source code for implementing TMSF-Net and conducting the experiments will be made publicly available in this repository upon acceptance of the associated paper.
